# Gadget Hub

Интернет-магазин гаджетов. Курсовой проект по дисциплине «Web-разработка».

## Структура

Проект состоит из двух независимых частей: frontend — клиентская часть на базе
React, Vite и React Router. backend — серверная часть на Node.js и Express. База
данных не используется; все данные о товарах, пользователях и заказах хранятся в
локальных JSON-файлах в директории backend/data/.

## Запуск backend

Проект запускается на двух локальных серверах в разных терминалах. Сервер
автоматически запускается на порту 8080. Настраивать переменные окружения не
требуется.

```
cd backend
npm install
node server.js
```

Откройте новое окно терминала, перейдите в папку клиента и запустите проект в
режиме разработки:

```
cd frontend
npm install
npm run dev -- --host
```
