# Лабораторная работа 5

## Задание

**Вариант 36: Модальное окно в магазине книг**

Требуется создать список книг, содержащий обложку и название. При клике на
карточку книги должно открываться модальное окно с подробной информацией.
Функциональность модального окна:

- открытие при клике на карточку книги;
- закрытие по кнопке (Х);
- закрытие по клику вне области модального окна (на оверлей);
- закрытие по нажатию кнопки `Esc`. Примечание: Запрещено использовать сторонние
  библиотеки для модальных окон.

## Реализация

Проект реализован на React без использования сторонних библиотек.

- **`App`**: Главный компонент. Хранит массив данных о книгах и состояния
  (`selectedBook`, `isModalOpen`). Отрисовывает сетку книг.
- **`Modal`**: Компонент модального окна. Принимает пропсы `isOpen`, `onClose` и
  `book`.
  - Использует `useEffect` для отслеживания события `keydown` (закрытие по
    `Escape`) и блокировки скролла `body`.
  - Имеет обработчик `onClick` на корневом элементе `.modal-overlay` для
    закрытия при клике вне окна.
  - Остановка всплытия события (stopPropagation) на `.modal-content`
    предотвращает ложные закрытия.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
